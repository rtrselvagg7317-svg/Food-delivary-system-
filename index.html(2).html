📚 How Queue and Priority Queue Work

Queue

A Queue follows FIFO — First In, First Out.

  • New normal orders enter at REAR.
  • Orders are processed from FRONT.
  • Fair ordering for normal delivery requests.

Example: FRONT → 101 → 102 → 103 → REAR

Priority Queue

Orders are processed according to priority.

  • 1 — Emergency
  • 2 — High Priority
  • 3 — Normal
  • Highest priority is processed first.

Example: FRONT → 205 Emergency → 203 High → 201 Normal → REAR

🎓 Project Documentation

Food Delivery Order Manager — Data Structures Project

Problem Statement

Food delivery platforms receive many orders. Normal orders should be handled fairly in arrival order, while urgent orders need faster processing.

Objectives

  • Implement FIFO Queue.
  • Implement Priority Queue.
  • Visualize operations in real time.
  • Demonstrate a practical DS application.

Algorithms

  • Enqueue normal order at rear.
  • Dequeue normal order from front.
  • Insert priority order by priority level.
  • Process highest-priority order first.

Advantages & Conclusion

Queue provides fair FIFO handling for normal orders. Priority Queue ensures emergency and high-priority orders are processed before lower-priority orders.
